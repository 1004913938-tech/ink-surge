# 面试实时字幕（轻量版）

飞书 / 腾讯会议 / Zoom 面试时，对方说英文 → 你屏幕上实时出中文字幕，**只有你看得到**。
一个网页文件（`index.html`），不用安装，不用服务器。

```
会议声音（Chrome 屏幕共享时带的系统声音，只在你电脑和 Deepgram 之间；已要求 Deepgram 不拿去训练模型）
   → Deepgram 实时识别英文（你的 Key，按秒计费，1 小时约 $0.3–0.5）
   → Chrome 自带离线翻译成中文（本机运行，免费，不上传）
   → 本页 + 置顶悬浮小窗
```

## 面试当天怎么组合

**用飞书电脑客户端入会 + 同时开着本页面（方案 B）**。飞书自带字幕（方案 A）能用就一起开，两个互为备份。
方案 C 只在电脑客户端用不了时应急。

| | 方案 A 飞书自带字幕 | 方案 B 本页面 | 方案 C Chrome 实时字幕 |
| --- | --- | --- | --- |
| 入会方式 | 飞书**电脑客户端** | 客户端或网页版都行 | 飞书**网页版**（Chrome 里） |
| 费用 | 免费 | Deepgram 约 $0.5/小时 | 免费 |
| 能不能用 | 取决于对方公司套餐和设置，**当天才知道** | 你自己能控制，周末可以彩排 | 你自己能控制 |
| 隐私 | 会议里会生成字幕记录 | 语音只发给 Deepgram 识别（已选择不参与模型训练）；翻译在本机 | 字幕文字发给 Google 翻译 |

## 方案 A：飞书自带字幕翻译

- 只有**电脑客户端**有（飞书官方说明：网页版入会不支持字幕）。
- 需要发起会议的公司是飞书商业版 / 企业版，并且管理员没有关掉字幕。所以面试时才知道有没有。
- 英语可以作为说话语言识别，翻译可以选简体中文。

**面试前（可选）**：飞书客户端 → 左上角头像 → 设置 → 视频会议 → 字幕 → 勾选「入会时开启字幕」（也可能叫「加入会议时开启字幕」）。如果有翻译语言选项，选「简体中文」。

**会议中**：
1. 点底部工具栏「字幕」。没有的话点「更多 ···」→「字幕」。
2. 鼠标移到字幕区域 → 右上角的翻译 / 字幕设置图标 → 「翻译为：简体中文」，可以勾选「同时显示原文和译文」。
3. 找不到「字幕」按钮，说明对方没开通，直接看方案 B。

说明：
- 菜单名称来自飞书帮助中心，版本不同可能略有差别。
- 开启后会议里会生成字幕记录（别人点「查看完整字幕」能看到内容）。没有资料说会通知对方是谁开的。
- 你共享屏幕时，对方看不到飞书字幕。

## 方案 B：本页面

### 需要什么

| 项目 | 要求 |
| --- | --- |
| 电脑 | Windows 10/11（Mac 需 macOS 14.2+） |
| 浏览器 | **电脑版 Chrome 138 或更新**。地址栏输入 `chrome://settings/help` 查看版本并更新 |
| Deepgram Key | 有余额。新账号送 $200 免费额度。查余额：登录 console.deepgram.com → 选项目 → Billing / Usage |
| 网络 | 能连 deepgram.com。第一次「准备翻译」要从 Google 下载约 76MB 语言包，在印尼直接能连 |

### 拿到文件

- 在 Claude 对话里下载 `index.html`，或者
- GitHub：仓库 `ink-surge` → 分支 `claude/conference-translation-research-buh1rm` → `livecaption/lite/index.html` → 右上角「Download raw file」。

放到桌面，**右键 → 打开方式 → Google Chrome**（默认浏览器不是 Chrome 时别直接双击）。

### 每次使用（4 步）

1. **填 Key**：粘贴 Deepgram Key（只存在你这台电脑的浏览器里）。语言保持「English 英语 → 中文」。
2. **点「准备翻译」**，等到显示「翻译已就绪」。
   - **每次打开本页都要点一下**，这是 Chrome 的规定。
   - 第一次要下载语言包，会显示进度；以后几秒就好。
3. **进会议之前**（或在飞书入会前的预览页），点「选择会议声音并开始」：
   - 弹窗选 **「整个屏幕」**；
   - 打开弹窗底部 **「同时分享系统音频」** 开关（英文版 Chrome 叫 Also share system audio。一定要开，没开就没有声音）；
   - 点「分享」；
   - 屏幕下方出现「…正在共享您的屏幕和音频」提示条，点 **「隐藏」**。**不要点旁边的「停止共享」**，点了字幕就停了，悬浮窗会出现红色提示；
   - 状态灯变绿「正在收听」。在飞书里做一次扬声器测试，本页的音量条应该跟着跳。
4. **点「悬浮字幕窗」**，把小窗拖到飞书视频旁边。
   - 窗口边缘可以拖大，选「大」字号时建议拉高一点。
   - 之后可以把飞书放大，悬浮窗一直在最上层；本页被飞书挡住也照常更新。

### 怎么看字幕

- 大字是中文，下面小字是英文原文。
- 虚线框是"正在说"的半句，带临时翻译；说完一句后定稿成实线框。延迟约 1–2 秒。
- 悬浮窗顶部一行是状态：绿点 = 正常，后面是已收听时长；右边是音量条。
- **悬浮窗出现红 / 黄横条 = 要注意了**，横条上写着原因：
  - 网络中断时会自动重连，几秒内恢复；可以点横条上的「立即重连」。
  - 写着「字幕已停止」：回到 Chrome 页面重新点「选择会议声音并开始」。
  - 黄条「20 秒没有会议声音」：还没进会、或你自己在回答时出现是正常的。
    如果对方在说话、音量条却不动，说明声音没录到，检查飞书扬声器和耳机（见注意 1）。
- 出现「⚠ 连接中断约 N 秒」这一行：这几秒对方说的话可能没出字幕，没听懂就请对方重复一下。
- 句末带「…（中断）」：这句话说到一半连接断了，后半句可能缺失。
- 面试结束点「停止」（按秒计费），再点「下载记录」保存整场中英对照文本。
  「清屏」只清屏幕，下载记录里内容还在。

### 一定要注意

1. **飞书的扬声器要选「系统默认」**（飞书 → 设置 → 音视频 → 扬声器）。Chrome 录的是 Windows 默认播放设备的声音。
   - 戴耳机的话，把耳机设成 Windows 默认播放设备（右下角喇叭图标 → 选耳机）。**面试中途不要插拔或切换耳机**。
   - 最稳的是**有线耳机**或电脑扬声器。蓝牙耳机在通话时可能切换成「耳机（免提）」设备，导致录不到声音；
     要用蓝牙耳机就一定在彩排时用飞书会议试一次，确认音量条会跳。
2. **面试中要共享屏幕时，在飞书里选「共享窗口」，只共享需要的那个窗口**，或者先关掉悬浮窗。
   如果共享整个屏幕，对方会看到字幕。
3. 本页标签页不要关、不要刷新（误点关闭时会弹出确认）。
4. 你自己说的话不会出字幕（只录对方的声音），这是正常的。

### 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 「20 秒没听到会议声音」 | 还没进会或你在回答时出现是正常的。对方在说话也出现：飞书扬声器不是系统默认设备，或蓝牙耳机切换了设备（见注意 1） |
| 「连不上 Deepgram」 | Key 复制错 / 余额为 0 / 网络问题 |
| 「没有选到声音」 | 弹窗里没打开「同时分享系统音频」开关，重新点开始再选一次 |
| 只有英文没有中文 | 没点「准备翻译」，或者 Chrome 版本太旧，看「准备翻译」旁边的提示 |
| 弹窗里没有「同时分享系统音频」开关 | 选了「窗口」或「标签页」；改选「整个屏幕」 |
| 悬浮窗打不开 | 需要电脑版 Chrome 116+；或者别的网页正在用画中画（Chrome 同时只允许一个画中画窗口） |

## 方案 C（应急）：飞书网页版 + Chrome 自带实时字幕翻译

只在飞书电脑客户端用不了时用。Chrome 的实时字幕**只能听到 Chrome 里播放的声音**，所以必须用网页版入会。
网页版没有飞书自带字幕；可以同时开方案 B，弹窗里选会议所在的**标签页**，并打开「分享标签页中的音频」。

1. 提前设置：
   1. 地址栏输入 `chrome://settings/accessibility`，打开「实时字幕」(Live Caption)，等提示语音文件下载完成。
   2. 实时字幕语言选 English。
   3. 打开「实时翻译」(Live Translate)，「将字幕翻译成」选「中文（简体）」。
2. 入会：在 Chrome 打开会议链接，点「网页版入会」（不要点「打开飞书」），再点「加入」。
   网页版可能要求登录或手机验证，周末先试一次。
3. 字幕框浮在 Chrome 窗口上，可以拖动、展开。字幕文字会发给 Google 翻译。

Windows 11 自带的「实时辅助字幕」能听到所有声音，但只有 Copilot+ 电脑才能翻译成中文。普通电脑只能出英文字幕，可以当最后的备份（Win + Ctrl + L 打开）。

## 面试前彩排（周六 / 周日各 15 分钟）

- [ ] Chrome 更新到最新，重启 Chrome。
- [ ] 安装并登录**飞书电脑客户端**（中国版），确认能用会议号入会。
- [ ] 打开本页 → 填 Key → 「准备翻译」到「翻译已就绪」。
- [ ] 在 Chrome 另一个标签页播放一段英文面试视频（YouTube 搜 "mock job interview english"），
      本页点开始 → 选整个屏幕 + 同时分享系统音频 → 看到中文字幕 → 打开悬浮窗 → 试字号、拖大小。
- [ ] 试一下故意点「停止共享」：悬浮窗应出现红色「字幕已停止」；再点开始恢复。
- [ ] 找朋友开一次**飞书会议**（他发起，你用电脑客户端以参会人身份加入），让他说英文，或对着麦克风放英文视频：
  - 试方案 B，再戴上面试要用的耳机试一次（蓝牙耳机尤其要试）；
  - 看看方案 A 的「字幕」按钮在不在。朋友是免费版的话大概率没有，这不代表面试时没有。
- [ ] 想有方案 C 备份：照上面设置好 Chrome 实时字幕，用飞书网页版入会试一次。
- [ ] Deepgram 后台确认余额 > $5。
- [ ] 面试当天提前 15 分钟：
  1. 打开本页 → 「准备翻译」→ 「选择会议声音并开始」（整个屏幕 + 同时分享系统音频）→ 打开悬浮窗；
  2. 打开飞书，做一次扬声器测试：本页和悬浮窗的音量条都应该跟着跳（不跳就检查注意 1）；
  3. 进会议。进会前出现「20 秒没有会议声音」是正常的。

## 费用和隐私

- Deepgram 按实际收听时长计费：英文 nova-3 约 $0.0048–0.0077/分钟，1 小时约 $0.3–0.5；打开「区分说话人」每小时另加约 $0.12。
- 会议声音只发给 Deepgram 做识别，并且页面已要求 Deepgram 不把录音用于模型训练（`mip_opt_out=true`）；翻译用 Chrome 本机模型，不上传。
- Key 只存在这台电脑的浏览器里。建议在 Deepgram 后台为面试单独建一个 Key，用完删掉。
- 字幕是辅助你听懂，回答还是你自己的。面试官问起，直说开着字幕辅助就好。

## 开发者

- 单测：`node --test livecaption/lite/tests/core.test.mjs`。覆盖纯逻辑：Deepgram 消息 → 句子、说话人分段、断线保留半句、重连间隔、错误提示。
- 浏览器端到端：`LC_DEPS=<含 playwright 和 ws 的 node_modules 所在目录> node livecaption/lite/tests/browser.e2e.mjs`。
  模拟 Deepgram 服务器 + Chromium，共 47 项检查，场景包括：
  - 两位说话人、半句预翻译；
  - 服务端重启后重连、网络闪断（连续握手失败）、服务端卡死、握手卡住时「立即重连」、迟到的断线仍标出中断；
  - 错误 Key、Key 格式不对 / 带空格、`file://` 打开、Deepgram 报错后恢复；
  - 会议声音静音时悬浮窗黄色提示；
  - 翻译抛错 / 卡死；
  - 悬浮窗状态与告警、误点「停止共享」；
  - 回看不跳动、导出、被遮挡时照常更新、双击开始。
- 测试钩子：
  - `?dg=ws://…` 换 Deepgram 地址；
  - `?fakeAudio=1` 用测试音代替屏幕共享，`?fakeAudio=silent` 用静音；
  - `?stall=` / `?trTimeout=` / `?silence=` 缩短卡死检测、翻译超时和无声提示（毫秒）。
- 与完整版的关系：完整版（LiveKit + agent）支持多人分人、多语种混说、听众扫码订阅；轻量版只做"一个人看一种语言"，零部署。
