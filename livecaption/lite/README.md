# 面试实时字幕（轻量版）

飞书 / 腾讯会议 / Zoom 面试时，对方说英文 → 你屏幕上实时出中文字幕，**只有你看得到**。
一个网页文件（`index.html`），不用安装，不用服务器。

```
会议声音（Chrome 屏幕共享时带的系统声音，不发给任何人）
   → Deepgram 实时识别英文（你的 Key，按秒计费，1 小时约 $0.5）
   → Chrome 自带离线翻译成中文（本机运行，免费，不上传）
   → 本页 + 置顶悬浮小窗
```

两个方案，**先试 A，A 不行用 B**；B 两个都可以同时开，互为备份。

## 方案 B：本页面

### 需要什么

| 项目 | 要求 |
| --- | --- |
| 电脑 | Windows 10/11（Mac 需 macOS 14.2+） |
| 浏览器 | **电脑版 Chrome 138 或更新**（地址栏输入 `chrome://settings/help` 看版本并更新）。Edge 能识别但没有内置翻译 |
| Deepgram Key | 有余额。查余额：登录 console.deepgram.com → 左侧 Billing / Usage |
| 网络 | 能连 deepgram.com；第一次准备翻译要从 Google 下载语言包（在印尼直接能连） |

### 拿到文件

- 在 Claude 对话里下载 `index.html`，或
- GitHub：仓库 `ink-surge` → 分支 `claude/conference-translation-research-buh1rm` → `livecaption/lite/index.html` → 右上角「Download raw file」。

放到桌面，**右键 → 打开方式 → Google Chrome**（默认浏览器不是 Chrome 时别直接双击）。

### 每次使用（4 步）

1. **填 Key**：粘贴 Deepgram Key（只存在你这台电脑的浏览器里）。语言保持「English 英语 → 中文」。
2. **准备翻译**：点「准备翻译」，等到显示「翻译已就绪」。第一次要下载语言包（几十 MB，进度会显示），以后秒开。
3. **进飞书会议**，然后回到本页点「选择会议声音并开始」：
   - 弹窗选 **「整个屏幕」**；
   - 打开弹窗底部 **「同时共享系统音频」** 开关（一定要开，没开就没有字幕）；
   - 点「共享」。屏幕底部出现「正在共享」提示条，点 **「隐藏」**。
   - 状态灯变绿「正在收听」，有人说话时音量条会跳。
4. **点「悬浮字幕窗」**，把小窗拖到飞书视频下方或旁边，调字号。之后可以把飞书放大，悬浮窗一直在最上层。

字幕：大字是中文，下面小字是英文原文；灰色虚线框是"正在说"的半句，说完一句后定稿。延迟约 1–2 秒。
面试结束后可以点「下载记录」保存整场中英对照文本。

### 一定要注意

1. **飞书的扬声器要选「系统默认」**（飞书 → 设置 → 音视频 → 扬声器）。Chrome 录的是 Windows 默认播放设备的声音；
   戴耳机就把耳机设成 Windows 默认播放设备（右下角喇叭图标 → 选耳机）。
2. **要在面试里共享屏幕时，先关掉悬浮窗**，或者在飞书里只共享某个窗口而不是整个屏幕，否则对方会看到字幕。
3. 本页标签页不要关、不要刷新；被飞书挡住或最小化都没关系（已测试：遮挡时悬浮窗照常更新）。
4. 你自己说的话不会出字幕（只录对方的声音），这是正常的。
5. 字幕停了：看状态灯。黄灯 = 自动重连中（几秒恢复）；红字提示 Key/余额/网络 = 按提示处理；
   仍不行就点「停止」→「选择会议声音并开始」重新选一次。

### 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 「20 秒没听到会议声音」 | 共享时没打开「系统音频」开关；或飞书扬声器不是系统默认设备（见注意 1） |
| 「连不上 Deepgram」 | Key 复制错（前后有空格）/ 余额为 0 / 网络拦截（开 VPN 再试） |
| 只有英文没有中文 | 第 2 步没完成；看「准备翻译」旁的提示。Chrome 版本太旧就更新 |
| 弹窗里没有「系统音频」开关 | 选了「窗口」或「标签页」；改选「整个屏幕」 |
| 悬浮窗打不开 | 需要电脑版 Chrome 116+；或者别的网页的画中画占用了（Chrome 只允许一个画中画窗口） |

## 面试前彩排（周六 / 周日各 15 分钟）

- [ ] Chrome 更新到最新，重启 Chrome。
- [ ] 打开本页 → 填 Key → 「准备翻译」到「翻译已就绪」。
- [ ] 在 Chrome 另一个标签页播放一段英文面试视频（YouTube 搜 "mock job interview english"），
      本页点开始 → 选整个屏幕 + 系统音频 → 看到中文字幕 → 打开悬浮窗 → 试字号。
- [ ] 找朋友开一次**飞书会议**（他发起，你用飞书客户端以参会人身份加入），让他说英文或对着麦克风播放英文视频：
      同时试方案 A 和方案 B；试一下戴耳机。
- [ ] Deepgram 后台确认余额 > $5（一场 1 小时面试约 $0.5）。
- [ ] 面试当天提前 15 分钟：打开飞书 → 扬声器测试（音量条应该跳）→ 本页开始 → 打开悬浮窗 → 再进会议。

## 开发者

- 单测（纯逻辑：Deepgram 消息 → 句子、说话人分段、错误提示）：`node --test livecaption/lite/tests/core.test.mjs`
- 浏览器端到端（模拟 Deepgram 服务器 + Chromium：两位说话人、半句预翻译、断线重连、错误 Key、`file://` 打开、悬浮窗、导出、被遮挡时更新）：
  `LC_DEPS=<含 playwright 和 ws 的 node_modules 所在目录> node livecaption/lite/tests/browser.e2e.mjs`
- 测试钩子：`?dg=ws://…` 换 Deepgram 地址，`?fakeAudio=1` 用测试音代替屏幕共享。
- 与完整版的关系：完整版（LiveKit + agent）支持多人分人、多语种混说、听众扫码订阅；轻量版只做"一个人看一种语言"，零部署。
